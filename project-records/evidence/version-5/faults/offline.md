## Reproducible offline commands and results

Run from `/home/zer0/main/jockey`:

```sh
cargo fmt --all --check
cargo test -p jocky-forensic -p jocky-native-linux --locked --offline
/tmp/jocky-t165-py/bin/python -m pytest tests/lab/linux -q
```

After all T166 edits, the focused Rust crates passed **1,051 tests across 55 suites** (`target/us2-final-focused.log`) and the Python lab harness passed **24 tests** (`target/us2-pytest.log`). Formatting and the optional journal-enabled native suite passed (`target/us2-journal.log`). The full workspace suite also passed (`target/us2-workspace.log`); that run began before the final array/privacy/replay additions, which the final focused run covers. The installed Clippy driver is 1.98.0, while these crates require 1.98.1, so Clippy is not recorded as a pass.

**Zero-read assertion:** pure admission denial has no source adapter; native confinement tests deny expired, cancelled, wrong-target, traversal and unrequested paths before an evidence read. The read double records zero calls for size, memory and invalid-permit prechecks. After an actual read fails, the bytes already returned remain charged; no successful prefix is emitted.

**Process/publication residue:** the synthetic crashed publisher test asserts the owned child is reaped, its stage is gone and reserved report bytes are not refunded. The symlink/pre-existing-stage negative asserts its outside sentinel stays byte-identical. Failed cleanup remains a typed failure. These are offline results; kernel-blocked cleanup, real filesystem failure and the complete live Debian T168 fault campaign remain unverified here.
